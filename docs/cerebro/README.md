# O cérebro mudou de lugar

O que esta pasta guardava (as armadilhas que já custaram horas, os defeitos que já aconteceram com o guarda que hoje impede cada um de voltar, e as decisões do dono com o motivo de cada uma) passou para o cofre do Obsidian em `cofre de contexto/arenaidle/`, que o dono criou para ser o segundo cérebro do projeto: lá cada armadilha e cada defeito é uma nota própria, ligada ao sistema que cita e à lição que ensinou, e há também as notas de sistemas, a lista do que cada teste protege e o que está em aberto, com a porta de entrada em `cofre de contexto/arenaidle/Comece aqui.md`. Esta pasta ficou só com este aviso porque dois cérebros são pior que um: o mesmo conhecimento escrito em dois lugares é exatamente o que envelhece em silêncio neste repositório, e o conhecimento novo deve ser escrito no cofre, não aqui.
